# Sistema de Gestión de Conciertos (Examen JS)

Este proyecto contiene la resolución de una evaluación práctica desarrollada en **JavaScript**, la cual implementa la lógica de un sistema interactivo para la gestión, reserva o venta de entradas para eventos y conciertos.

---

## 🛠️ Tecnologías Utilizadas

* **JavaScript:** Lógica de negocio, manejo de eventos y control de estado de la aplicación.
* **HTML5:** Estructura e interfaz base para la interacción del usuario.
* **CSS3:** Estilos y maquetación visual del proyecto.
